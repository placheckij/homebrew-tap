# homebrew-tap

The Homebrew tap for agent-bridge from
[claude-remote-mcp](https://github.com/placheckij/claude-remote-mcp).

## Install

```sh
brew install placheckij/tap/agent-bridge
agent-bridge setup
```

agent-bridge's release workflow updates the formula on each release, so do not edit
it by hand.

See the [agent-bridge README](https://github.com/placheckij/claude-remote-mcp/tree/main/agent-bridge#readme)
for setup and usage.
